# Fuffy-Furry-Text-Editor
I was bored, so I decided to make a simple Python text editor!

# How to build:
pyinstaller --onedir --windowed --collect-all customtkinter FuffyTextEditor.py

^^^^^ Command for turning it into an executable.

Just make sure to use the other thing to make a sort of "Shortcut" for it!

Linux Mint "shortcut" thing:
[Desktop Entry]
Name=Fuffy Furry Text Editor
Comment=A custom text editor built with Python and CustomTkinter
Exec=Path To executable!
Icon=Path to icon!
Terminal=false
Type=Application
Categories=Utility;TextEditor;

For windows just right click the executable in the Dist file and press "Create Shortcut"
